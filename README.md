# 城市 AI 小警察 · 杭州文明巡逻计划

一款原创的、纯前端的 2D 文明交通科普小游戏。驾驶友善的 AI 无人机“小杭”，在杭州主题小城市中完成 60 秒巡逻，发现交通问题，通过对话传递安全知识。

## 打开就能玩

双击本目录的 **index.html**，用 Edge、Chrome、Firefox 或 Safari 打开即可。无需安装、注册、联网、构建或启动后端。

首次使用先点击“开始巡逻”；手机上可以直接点击地图中的“起飞”。

## 这次扩展

实际世界从 **1200 × 800** 扩到 **3000 × 2000**，可飞行面积为原来的 **6.25 倍**。主画面只显示城市的一部分，镜头随无人机移动。原先 4 类、8 个重复目标，改为 **20 类各不相同的事件，每局每类仅出现一次**。

六片可探索街区：西湖湖滨、运河拱宸、东站枢纽、之江文旅、滨江科创、钱江新城。新增路网、钱塘江与跨江桥、运河院落、东站站房及接驳广场、龙井茶园、文化馆、科技园区、运动公园、市民广场和江畔亭。

城市布局已进一步修整：运河民居退回街区地块，站房与市民广场避开道路，桥西院落保留运河水面，莲花亭周边不再叠放住宅。检查建筑屋檐、阴影与地块边界，避免建筑占用道路、路口、人行道及运河。

空地新增 20 处主题设施与花境，包含便民小集、单车接驳点、茶香慢行园、阅读角、滨水花园、充电驿站、居民球场、儿童乐园和市民共享花园；沿江增设步道、座椅、绿树，居民楼前补充庭院小径、花坛和单车架，科创园屋顶补充太阳能板。

## 玩法

- 点击“开始巡逻”，或手机地图内的“起飞”，开始 **60 秒**巡逻。
- 用 **WASD / 方向键 / 触屏方向键**驾驶。按住 **Shift**，或点击地图内的**加速按钮**，提升飞行速度。
- 可以点击主地图选择目的地，也能点击**小地图**前往远处的街区。小地图框线表示当前视野，绿点表示无人机，橙点表示待劝导事件。
- 点击主地图或小地图上的事件标记，小杭会实际飞近并扫描；也可点击侧栏“附近优先巡查”的事件导航。不会传送，也不会扩大扫描距离。
- 靠近目标后，按 **空格 / 扫描取证**进行扫描。
- 对话期间城市、镜头和倒计时一起暂停。每起都有独立的提醒、认错回应、知识卡和纠正画面。
- 阅读后点击“谢谢配合，一起文明出行”，获得 **100 分**，目标变绿，每个事件只能计分一次。
- **60 秒结束或 20 起全部完成**后结算，最高 **2000 分**，报告展示学到的知识和探索街区数。
- 重玩时，新增 16 类事件重新分配到不同位置，四个基础事件保留熟悉的起步区域。
- **P / Esc**或暂停按钮可暂停；切换标签页或窗口失焦时自动暂停。

## 窗口与手机适配

- 电脑端随浏览器宽度和高度分配地图空间，任务详情独立滚动，起飞/扫描按钮固定在任务面板底部；矮窗口自动精简标题与提示。
- 窄窗口和平板竖屏采用上下布局。手机起飞后收起介绍区，地图及方向、扫描、暂停、计时、积分、加速、小地图在当前画面内可用，详细任务继续保留在地图下方。
- 手机横屏重新排列操作区，小地图与扫描按钮并排，避免挤压计时栏。触屏方向键、暂停和主要操作按钮至少为 44px。
- 使用动态视口高度与安全区内边距适应手机浏览器工具栏和屏幕边缘。Canvas 根据容器尺寸、窗口变化和像素密度重绘，地图保持等比显示。
- 窗口缩放与横竖屏切换保留无人机位置、事件进度、分数和当前巡逻；对话中的时停也继续保留。
- responsive-verification.json 记录 320×480 至 2560×1440 的 19 种尺寸验收，以及实时窗口缩放、屏幕旋转、弹窗、触屏和高像素密度检查。

## 杭州元素与设计

原创的西湖青绿、暖白配色与手绘感城市插画。场景包含西湖、苏堤意象、断桥、雷峰塔、柳浪闻莺、湖滨老街、武林广场、京杭大运河、钱江新城和钱塘江，并通过“礼让行人”等对话连接杭州文明出行主题。

地图为美术化虚拟科普场景，位置与路网经过重组。游戏中的市民、学校、街道与情节为虚构。AI 角色使用本地规则逻辑；没有真实人脸识别、执法或云端模型服务。

音效默认关闭，可在右上角开启。使用本地 Web Audio 合成提示音，不加载外部音频。系统选择“减少动态效果”时会减少旋转、波动和转场。

## 巡逻档案

记录最近 10 次巡逻，展示积分、劝导数量、称号和时间。数据只保存在当前浏览器的 localStorage。浏览器限制本地存储时仍然可以游玩；不同浏览器或地址的记录不会互通。

## 技术与验证

原生 HTML + CSS + JavaScript + Canvas 2D，不依赖框架、CDN、npm 包或后端。六片街区的城市背景预绘制缓存，动画使用单个 requestAnimationFrame 循环，画布像素密度上限为 2。无人机采用与帧率无关的速度平滑，斜向移动归一化；世界坐标、跟随镜头、点击坐标转换与小地图共享同一空间定义。

游戏状态包括待命、巡逻、科普对话、暂停、查看手册/档案、结束。所有时停状态共享冻结规则，防止阅读期间扣时。目标只能完成一次，避免重复计分。

浏览器验收使用 Microsoft Edge / Playwright，覆盖真实点击飞行、键盘驾驶、触屏方向键、全部 20 个不同目标、对话时间冻结、暂停恢复、60 秒截止、满分结算、重玩、档案持久化、减少动态效果及 320–1920px 布局。

布局验收覆盖全部建筑的屋顶与阴影、20 处新增地块：不与道路、人行道或运河重叠，建筑之间也不重叠；公园与设施不能覆盖其他建筑，阅读角自身的小书屋除外。地图改动后的巡逻流程仍通过完整浏览器验收。
